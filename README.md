This repository hosts the source code for my professional portfolio and resume website. It represents a significant upgrade from a traditional static document, providing a comprehensive, dynamic, and interactive presentation of my entire professional profile.
**Why a Website?**
The site goes beyond the confines of a single-page PDF to offer an enhanced candidate experience:
**Dynamic Presentation:** Rather than static text, the site uses modern UI/UX to effectively showcase my qualifications, work history, skills, and personal projects in an engaging format.
**Deep Dive into Projects:** Every project listed includes dedicated pages with detailed breakdowns, tech stack specifics, images, and, where possible, links to live demos or running applications. This allows reviewers to evaluate technical depth directly.
**Accessibility and Responsiveness:** The design is fully responsive, ensuring optimal viewing and navigation across desktop, tablet, and mobile devices.
**Continuously Updated:** It serves as a single, centralized location for the absolute latest version of my career history, always available 24/7.
