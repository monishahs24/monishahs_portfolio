This repository contains the full source code for my professional portfolio and resume website, which I've engineered to serve as a dynamic, interactive presentation of my entire professional profile. Moving beyond the limitations of a static PDF, this site utilizes to showcase my qualifications, detailed work history, core skills, and personal projects in a single, accessible, and fully responsive location. Crucially, the site allows potential employers and collaborators to take a deep dive into my technical achievements, offering detailed write-ups and, where available, live demos for projects, thereby providing richer context than a traditional resume. The latest printable version and the static PDF resume file are also maintained within this repository for those requiring a conventional document format.
